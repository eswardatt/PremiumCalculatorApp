# PremiumAPI – Insurance Premium Calculation Service (ASP.NET Core 8)

PremiumAPI is a RESTful Web API built using **ASP.NET Core 8**, designed to calculate monthly insurance premiums based on user information and occupation risk factors.

This service is consumed by an Angular 17 frontend application.

---

## 🚀 Features

- Calculate monthly premium using business formula  
- Provide list of occupations and mapped rating factors  
- Global exception handling middleware  
- CORS enabled for Angular UI  
- Modular architecture (Controller → Service → Models)  
- NUnit-based test project with code coverage support
